### DevOps and software development

.NET 11 Release Candidate 2 is now available with improvements across the runtime, libraries, SDK, and ASP.NET Core among other components, so teams running .NET workloads should review the changes for their environments. On the PostgreSQL side, PgBouncer 1.26.1 addresses three CVEs including a critical authentication bypass affecting SCRAM users, making this a priority update for production deployments. GitHub has released several security and management improvements for GitHub Apps to help teams move away from classic personal access tokens and adopt least privilege access patterns. Additionally, Gemini 4 Argon is now generally available in GitHub Copilot for complex coding and reasoning tasks, which may be relevant for development workflows. On the infrastructure front, Let's Encrypt is shortening certificate lifetimes over the next two years, which will roughly double daily renewal requests and may impact certificate management automation in your pipelines. Several DevOps focused posts discuss Terraform policy guardrails and a new schema management tool for PostgreSQL that keeps definitions in version control as YAML.
