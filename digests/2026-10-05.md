### DevOps and software development

Several items merit attention this week. Kubernetes v1.37 has graduated the metrics API to stable, which improves the reliability of resource monitoring and autoscaling for your clusters. On the security front, pgvector 0.8.7 fixes a critical buffer overflow vulnerability that can lead to arbitrary code execution, so upgrading should be prioritized if you use vector search with PostgreSQL. CISA continues tracking actively exploited vulnerabilities weekly, and this week added six new entries to its Known Exploited Vulnerabilities catalogue, making it worth monitoring for patches that affect your infrastructure. GitHub Actions is retiring the macOS 14 runner image on November 2, so any CI/CD pipelines using that image will need updating. PostgreSQL extensions including pg_ivm and pg_vault_tde have also released new versions with stability improvements and feature additions.
