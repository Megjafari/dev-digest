### DevOps and software development

AI agents are moving into production environments but bringing fresh security concerns. The Docker Blog covers containment strategies including sandboxes and credential exposure risks, while dev.to discusses practical pitfalls like non-deterministic outputs from LLM-based agents and runaway background jobs consuming your API budget. On the infrastructure side, Kubernetes job scheduling with Kueue can leave jobs suspended without clear visibility, and worker node recycling may silently interrupt running tasks if you lack proper job persistence. PostgreSQL users should upgrade psqlODBC immediately for a security fix, and new schema versioning tools are available through Perseid. GitHub Actions now offers dependency lockfiles in public preview and secret scanning for Anthropic keys, which blocks suspicious patterns by default.
